01 OUR PURPOSE

Small technology.
A meaningful connection.

Our first step is deliberately focused: test whether a short video can provide a usable nose image, compare it against registered records, and assign a persistent identity to a dog. This is a prototype — real-world recognition performance must be measured, not assumed.

🐾01 / PRIMARY IDENTIFICATION

Nose-print first

Use a short, safe-distance nose video and select its clearest frame to create a candidate signature for comparison with registered dogs.

♡
✦02 / UNIQUE DOG ID

A record that stays

When a dog is registered, the system assigns a persistent Dog ID and stores basic identity, area and status fields for future lookups.

✿
▦03 / BACKUP PATH

QR when needed

Each registered record can have a printable QR tag as a secondary option when lighting, movement or image quality makes a nose scan impractical.

02 HOW IT WORKS

Four steps.
One clearer ID.

The proposed pipeline is built around a short video, image-quality checks, feature comparison and a simple registration route when no reliable match is found.

01
Capture a 2-second videoA caregiver sends a clear nose clip through the intended WhatsApp flow or uses the local prototype.
📷
02
Find the clearest frameOpenCV checks frame sharpness; image enhancement can help with contrast. The current starter uses a placeholder crop, so a validated snout detector is still needed.
✦
03
Compare registered signaturesThe prototype compares feature vectors and returns a candidate match, low-confidence review or no-match result.
♡
04
Confirm or registerReview possible duplicates, assign a unique Dog ID, and generate a QR fallback tag for the registered record.

03 DOG REGISTRY & QR FALLBACK

Every registered dog
gets a place in the story.

The registry keeps the prototype's core purpose focused: a stable Dog ID and a basic record that can be found again. A QR tag provides a second route when a nose scan cannot be used.

  • ♡ Persistent Dog ID
  • ✿ Area, vaccination and sterilisation status fields
  • ▦ QR image generated for download

This starter stores data locally in a JSON file. Do not use real personal or sensitive data until authentication, access controls, backups and privacy review are implemented.
